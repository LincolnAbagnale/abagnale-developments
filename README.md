# Abagnale Developments

Site estático com a grade dos projetos: `public/index.html`.

**Cloudflare Pages:** Build command vazio · Build output directory `public`. Domínio: abagnaledevelopments.com.br.

**Adicionar um projeto:** em `public/index.html`, copie um bloco `<a class="item">` e troque imagem, nome, descrição e link. O logo vai em `public/img/` (400×400, `.webp`).
